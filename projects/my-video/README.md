# my-video

Proyecto Remotion en blanco.

## Comandos

```bash
npm install        # instalar dependencias
npm run dev        # abrir Remotion Studio
npm run build      # renderizar a out/video.mp4
npm run upgrade    # actualizar Remotion
```

- Composiciones: `src/Root.tsx`
- Escena de ejemplo: `src/Composition.tsx`
- Recursos estáticos (imágenes, audio): `public/`

Documentación: https://www.remotion.dev/docs
